# 🛡️ حارس كلمات السر — PassGuard

أداة ويب بسيطة ومفتوحة المصدر لـ**فحص قوة كلمات السر** و**توليد كلمات سر قوية**.
تعمل بالكامل داخل متصفحك — **لا تُرسل أي بيانات إلى أي خادم**، ولا تحتاج إنترنت بعد فتحها.

## المزايا
- 🔎 **فاحص قوة**: يقيس "الإنتروبي" (bits)، ويعرض تقديرًا لزمن الكسر، وقائمة فحوص عملية.
- 🎲 **مولّد آمن**: يستخدم `crypto.getRandomValues` (عشوائية تشفيرية، ليست ضعيفة)، مع خلط Fisher–Yates وضمان تنوّع الحروف.
- 🔒 **خصوصية كاملة**: ملف HTML واحد، بدون أي اتصال خارجي.
- 🌙 واجهة عربية بتصميم داكن تعمل على الموبايل والكمبيوتر.

## التشغيل
افتح `index.html` في أي متصفح — وبس. لا يوجد أي تثبيت أو بناء.

## الأمان (ملاحظات)
- تقدير زمن الكسر افتراضي تقريبي (≈10¹⁰ تخمينة/ثانية كأسوأ حالة) ويُستخدم للتوعية فقط.
- استعمل كلمة سر **مختلفة لكل حساب**، وفعّل **المصادقة الثنائية (2FA)**، واعتمد على **مدير كلمات سر**.
